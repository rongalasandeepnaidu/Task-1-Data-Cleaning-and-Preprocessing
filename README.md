# Task-1: Data Cleaning and Preprocessing

## Objective
Clean and preprocess the Netflix Movies and TV Shows dataset using Python and Pandas.

## Dataset
- netflix_titles.csv

## Steps Performed
1. Loaded the dataset using Pandas.
2. Checked for missing values.
3. Filled missing values with "Unknown".
4. Removed duplicate records.
5. Kept the `date_added` column unchanged.
6. Saved the cleaned dataset as `netflix_titles_cleaned.xlsx`.
